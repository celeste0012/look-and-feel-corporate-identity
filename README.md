### HTML
Ik heb voor het eerst een fieldset gebruikt:
```html 

          <Fieldset>
            <legend>Variant</legend>
                <label class="label-filter">
                    <input type="radio" name="variant" value="regular" id="variant_regular" checked>Regular</label>
                <label class="label-filter">
                    <input type="radio" name="variant" value="line" id="variant_line">Line</label>
                <label class="label-filter">
                    <input type="radio" name="variant" value="fill" id="variant_fill">Fill</label>
                <label class="label-filter">
                    <input type="radio" name="variant" value="diapositive" id="variant_diapositive">Diapositive</label>
            </Fieldset>
```
